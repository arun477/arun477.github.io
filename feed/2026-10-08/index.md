# GPT-6.1 Sol gets Ultrafast; Anthropic launches Cyber Mission

OpenAI made its Sol model up to 8x faster in the API and Codex, and Anthropic launched an effort to secure critical infrastructure and open source.


- [OpenAI rolls out Ultrafast mode for GPT-6.1 Sol](https://x.com/OpenAIDevs/status/2108262812489531498) (OpenAI Developers, release, Models): Up to 8x faster than standard Sol across the API, Codex and ChatGPT Work, making near-top-tier models practical for interactive agent loops.
- [Anthropic launches the Cyber Mission to secure critical infrastructure and open source](https://x.com/AnthropicAI/status/2108302539498414208) (Anthropic, news, Security): A dedicated effort to use its models to find and fix vulnerabilities in critical systems and open-source software.
- [Claude adds live dashboards and animated explainers in beta](https://x.com/claudeai/status/2108271552991252810) (Claude, news, Agents): Claude Dashboards and Claude Motion turn data and ideas into live, shareable artifacts, pushing chat assistants toward building small apps.
- [Grok Bot can now help run a Shopify store](https://x.com/bot/status/2108228871938359347) (Grok Bot, release, Agents): Connected to Shopify, the personal agent checks orders, tracks inventory and updates listings. Personal agents are taking on small-business operations.
