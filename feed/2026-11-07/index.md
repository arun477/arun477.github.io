# Agents get your real browser, and the tools that make it cheap

A quiet Saturday. OpenCode shipped an open-source way for any MCP agent to drive your own browser with handoffs for logins, and LangChain published hard numbers on how much browser-tool design changes agent cost and speed.


- [OpenCode Browse lets any MCP agent use your real browser](https://opencode.ai/product/browse) (OpenCode, news, Agents): An open-source MCP server and Chromium extension that lets OpenCode, Claude Code, Cursor or Codex drive your own browser with your logins, handing the tab back to you for 2FA or payments, with per-session site allowlists.
- [How LangChain optimized browser use for Deep Agents](https://www.langchain.com/blog/how-we-optimized-browser-use-for-deep-agents) (LangChain, blog, Agents): A measured comparison of seven browser toolsets: code-mode Stagehand passed 90% of WebVoyager for about $2 versus 78% and $27 for Playwright MCP, plus a trace-driven fix to agent sleeps that cut median task time by a third.
