# Gemini 4 Carbon leads a new private benchmark; AI vets Yang-Mills

Google DeepMind's Gemini 4 Carbon tops the new Artificial Analysis Index v5, which now scores mostly on private tests. Mistral ships a Responses API for agents, KITP convenes a review of an AI Yang-Mills result, and Anthropic finds analysts follow their agent's hidden lean.


- **Spike.** [Google DeepMind announces Gemini 4 Carbon, its new frontier model](https://deepmind.google/blog/gemini-4-carbon-our-next-frontier-model/) (Google DeepMind, release, Models, 22:39 UTC): Two weeks after Argon, Carbon tops Artificial Analysis's new Index v5 at 59 and leads cyber benchmarks like SEC-bench Pro (88.2%). Access starts with vetted cyber defenders; wider developer release comes later at $2/$10 per million tokens.
- [Physicists led by David Gross convene to vet an AI result on Yang-Mills theory](https://www.kitp.ucsb.edu/statement-by-the-yangmills-working-group) (KITP, news, research, 13:44 UTC): KITP formed a working group chaired by Nobel laureate David Gross to vet an AI result that includes a proof that quantum Yang-Mills theory exists, half of a Millennium Prize problem. OpenAI amplified it, so physicists are now formally checking model-made frontier science.
- [Anthropic trial: expert analysts followed Claude Code's hidden lean 86% of the time](https://www.anthropic.com/research/agents-judgment-calls) (Anthropic, paper, agents, 13:44 UTC): In a randomized study, 50 expert analysts using Claude Code went with their agent's secret, coin-flipped lean on 86% of judgment calls versus about 50% by chance. Most reused its arguments but only 15% credited it, a warning for anyone building advisory agents.
- [Artificial Analysis Intelligence Index v5 moves most of its tests to private sets](https://x.com/ArtificialAnlys/status/2115265133467635877) (Artificial Analysis, news, Benchmarks): The most-cited model leaderboard now scores mostly on private, held-out data, with new agentic coding and terminal benchmarks, which makes benchmark gaming harder. Expect labs to quote v5 numbers in upcoming launches.
- [Mistral launches a Responses API in public preview for building agents](https://x.com/MistralAI/status/2115443720371814478) (Mistral AI, release, Agents): Each response returns the model's answer, its reasoning and its tool calls as separate items, giving agent builders on Mistral a structured loop similar to OpenAI's Responses API.
- [Meta Andromeda: ads retrieval at over a billion ads per second on one GPU server](https://engineering.fb.com/2026/10/28/ml-applications/meta-andromeda-next-gen-ads-retrieval-gpu-co-design/) (Meta Engineering, blog, Infra): A detailed case of model-system co-design: a mixture-of-experts retrieval model with about 300x fewer FLOPs, one fused GPU kernel, and index matching moved onto the GPU to cut network traffic about 100x.
- [Simon Willison: October 2026 is the inflection point for vibe-coded games](https://simonwillison.net/2026/Oct/28/vibe-game-development/) (Simon Willison, blog, Agents): Four browser games built with Claude Opus 5.5 with almost no code review, prompts and transcripts included. His finding: models can now design for fun, not just ship something that looks like a game, and GPT-6 Astra still lags there.
