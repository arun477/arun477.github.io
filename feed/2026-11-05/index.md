# Claude Personal Finance; Perplexity Teammates; Muse Voice

Consumer agents get bank access, persistent coworkers and voice; Cursor and Mistral ship deploy paths; Cloudflare and Stripe meet agents on the web.


- **Spike.** [Thinking Machines ships Inkling 2 Small, a 594B/17B MoE for agents and coding](https://thinkingmachines.ai/news/inkling-2-small/) (Thinking Machines, release, Models, 14:10 UTC): Second-generation Inkling scores 31 on the AA Intelligence Index; available now on Tinker for inference and fine-tuning, with Apache 2.0 weights planned next week after safety checks.
- **Spike.** [Claude adds Personal Finance: read-only bank and card connections via Plaid](https://claude.com/resources/articles/introducing-personal-finance-in-claude) (claude.com, news, Agents, 22:34 UTC): US Pro/Max/Ultra beta lets Claude answer money questions from balances and up to two years of transactions you connect; access is read-only and hub chats are not used for training.
- [OpenAI's autonomous pipeline found and patched 948 Linux kernel privilege-escalation bugs in one run](https://openai.com/index/a-thousand-fewer-paths-to-root/) (openai.com, news, security, 13:36 UTC): An upcoming OpenAI cyber model, run in an autonomous pipeline, found, validated and patched 948 Linux kernel privilege-escalation bugs in a single run, a concrete marker for security agents.
- [OpenAI ships ChatGPT Images 2.6 and two faster GPT-Image-2.6 API models](https://openai.com/index/introducing-images-2-6/) (openai.com, release, 13:36 UTC): ChatGPT Images 2.6 adds GIFs and reference images, and the new API models Flare and Sunburst generate images about 50% faster, with Sunburst keeping details more consistent across edits. They're also available in Codex.
- [Perplexity launches Teammates, persistent agents that own ongoing work inside Computer](https://www.perplexity.ai/hub/blog/teammates-are-agents-for-complex-ongoing-work) (perplexity.ai, news, Agents): Max-tier teammates plan and follow through on long-running jobs using Computer tasks, skills, memory and tools, can collaborate with other teammates and message coworkers in Slack.
- [Meta rolls out Muse Voice and Realtime Avatar in the US](https://about.fb.com/news/2026/11/introducing-muse-ai-voice-expressive-avatars/) (about.fb.com, news, Agents): US users can talk to Muse in real time on mobile, web and Mac, with expressive avatars; voice is coming next to AI Glasses and Muse Charm.
- [Cursor Cloud Agents can build, host and share live web apps from a prompt](https://cursor.com/docs/cloud-agent/apps) (cursor.com, news, Agents): Describe a tool and Cursor scaffolds it, provisions Postgres if needed, runs security checks, and returns a shareable hosted URL behind Cursor auth or a public link.
- [Mistral Studio adds managed agents and apps for durable enterprise agent deployments](https://mistral.ai/news/build-with-studio/) (mistral.ai, news, Agents): Studio now runs long-lived managed agents with approvals, sandboxes and tracing, plus one-command app deploy, on shared infrastructure with Le Chonk.
- [Cloudflare adds personal-agent analytics and granular access policies for sites](https://blog.cloudflare.com/personal-agents-visibility-control/) (blog.cloudflare.com, news, Agents): Site owners can see which verified personal agents hit which paths on their behalf and set finer allow/block rules as agents become a first-class traffic class.
- [Stripe lets any business analyze payments data through an agent via MCP](https://stripe.com/blog/analyze-your-stripe-data-directly-with-your-agent) (stripe.com, news, Agents): Natural-language queries over Stripe data for reports, fraud and retention metrics are generally available; agents connect through the Stripe MCP or Queries API.
- [Inside GitHub's new Git storage architecture](https://github.blog/engineering/architecture-optimization/inside-githubs-new-git-storage-architecture/) (GitHub Engineering, blog, Infra): A detailed write-up of how GitHub redesigned Git object storage for scale, with the failure modes and tradeoffs that drove the new design.
- [How Figma built Nimbus to run tens of thousands of AI sandboxes](https://www.figma.com/blog/how-figma-manages-sandboxes-at-scale/) (Figma, blog, Infra): Figma's AI products need many isolated sandboxes for untrusted code; Nimbus is the internal platform that makes them fast, reliable and operable at that scale.
- [Cloudflare on why sites must treat personal agents as a new intermediary class](https://blog.cloudflare.com/trusted-agent-delegation/) (Cloudflare, blog, Agents): A clear framing of how personal agents strip user identity from requests and a collaborative approach for sites to identify, allow and manage that traffic safely.
