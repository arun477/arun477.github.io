# Gemini agents beat Minecraft; Claude designs quantum circuits

Four Gemini 4 Argon agents finished Minecraft from scratch using only code, and Anthropic showed Claude designing efficient quantum circuits.


- [Four Gemini 4 Argon agents beat Minecraft from scratch in 27 hours](https://x.com/GoogleDeepMind/status/2111127991401247033) (Google DeepMind, news, Agents): Working only through code and text, the agents wrote 2,783 programs and split up jobs over chat, a vivid long-horizon multi-agent result.
- [Claude Mythos 5 designs more efficient quantum circuits from plain-language instructions](https://x.com/AnthropicAI/status/2111152183240511640) (Anthropic, paper, Research): From Anthropic's STEM Fellows: a concrete case of a model doing useful design work in a specialised science domain.
- [Advancing generative recommendation inference with NVIDIA TensorRT-LLM](https://engineering.atspotify.com/2026/10/advancing-generative-recommendation-inference-our-collaboration-with-nvidia-on-tensorrt-llm/) (Spotify Engineering, blog, Infra): How Spotify serves LLM-style generative recommenders in production with TensorRT-LLM. Inference optimization beyond chatbots.
- [Ontology-driven observability: an end-to-end knowledge graph at Netflix scale](https://netflixtechblog.com/ontology-driven-observability-building-an-end-to-end-knowledge-graph-at-netflix-scale-421392cf5adf) (Netflix Tech Blog, blog): Netflix describes how it modelled its infrastructure as an ontology-backed knowledge graph so engineers and GenAI tools can trace incidents across services handling billions of requests a day.
- [Grounding AI agents in biological reality: building blocks for autonomous wet labs](https://research.google/blog/grounding-ai-agents-in-biological-reality-building-blocks-for-autonomous-wet-labs/) (Google Research, blog): Google Research lays out the pieces needed for AI agents to run real lab experiments with robotics, and how it keeps agent plans tied to what actually happens at the bench.
- [Scaling Indic pretraining: 2.8 trillion tokens and an open data generation pipeline](https://huggingface.co/blog/nvidia/scaling-indic-pretraining) (Hugging Face, blog): NVIDIA explains how it built a 2.8T-token pretraining corpus for Indian languages and open-sourced the synthetic data generation pipeline behind it.
