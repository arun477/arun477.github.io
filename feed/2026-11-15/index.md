# AI tackles the Standard Model; FBI flags an attack agent

A quiet weekend. OpenAI opened a science blog with a physicist's account of GPT-6 Astra leading the proof behind a candidate lattice definition of the Standard Model, and the FBI detailed how attackers are using the ARTEX agent framework.


- [GPT-6 Astra helps a physicist propose a lattice definition of the Standard Model](https://openai.com/index/step-toward-defining-the-standard-model) (OpenAI, news, Research): UCSB's Nathaniel Craig says Astra helped build the construction and led the proof for a candidate nonperturbative definition, a 50-year-old open problem, now under expert review. It opens OpenAI's new science blog.
- [FBI warns attackers are using the ARTEX agent framework to automate intrusions](https://www.ic3.gov/CSA/2026/261113.pdf) (FBI, news, Security): The FLASH says the open-source, LLM-driven pentest tool reached privileged access in under three hours and was used in the ConnectWise backup compromise; 1,600+ consoles are exposed. Lists IOCs and steps to lock down cloud and API access.
