Meta and Reflection ship big open-weight models; agents go parallel

Two large US open-weight models landed within a day: Meta's Muse Spark Open and Reflection's Apache-licensed Beam. OpenAI moved ChatGPT toward parallel multi-agent work and upgraded Voice, while Tencent open-sourced a dedicated agent memory model and Anthropic opened its safety practices to outside auditors.

Saturday 17 October 2026Updated 04:40 UTC

  1. SpikeAI at MetaNewsModels17:08 UTCMeta releases Muse Spark Open, an 816B open-weight model for coding and agents816B total, 42B active, 1M-token context. Artificial Analysis ranks it the top US open-weight model, though the licence requires attribution and a deal for providers over $20M.↗
  2. ReflectionNewsOpen sourceReflection releases Beam with open weights under Apache 2.0A second large open model in a day, but with a fully permissive licence: weights, tokenizer, reference code and FP8/NVFP4 builds, so teams can self-host and ship commercially with no strings.↗
  3. OpenAINewsAgentsChatGPT Pro can now run multiple agents on one task in parallelGPT-6 Pro splits a task across agents you can monitor and review individually, a sign that parallel multi-agent workflows are moving from dev tools into the mainstream chat product.↗
  4. Tencent HyNewsAgentsTencent open-sources Hy Memory 2.0, a model just for agent memoryA 30B (3B active) model, framework and cross-tool sync for deciding what agents should remember. Memory is becoming its own layer of the agent stack rather than a prompt trick.↗
  5. AnthropicNewsSafetyAnthropic gives METR employee-like access to audit its safety practicesMoves third-party evaluation from testing finished models to inspecting how a lab actually works internally, a possible template for other labs and regulators.↗
  6. OpenAINewsModelsOpenAI upgrades ChatGPT Voice with GPT-Live-1.1New voices and accents, including Hindi, and less stalling, rolling out to all users with API access next. Part of a wider voice race that also saw Grok Voice 3.0 top a reliability benchmark.↗
  7. Simons FoundationNewsResearchSimons Foundation, OpenAI and Anthropic commit $15M to AI in maths researchWorkshops and free compute to help mathematicians verify and build on AI-generated results, after OpenAI's batch of 700 AI-written papers unsettled the field.↗
  8. Anthropic EngineeringBlogInfraRedesigning source control at AnthropicMerges grew more than tenfold as agents took on more work, so a seven-person team replaced Git with an in-house version control system in five months.↗
  9. EarendilBlogAgentsPi Durable on CloudflareA worked build of long-running pi agents: one session per Durable Object with SQLite storage, hibernation when idle, alarm wakeups and a search subagent.↗
  10. VercelBlogSecurityFindings from the $1M Vercel Sandbox challengeAn open challenge to break out of Vercel's agent sandbox drew 1,285 reports, found a Linux kernel zero-day and paid $242K. Real data on how well agent isolation holds up.↗
