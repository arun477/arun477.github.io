# Mistral Large 4 lands; OpenAI shares new maths results

Mistral shipped a 1T-parameter open model, OpenAI released maths results from an internal model, and Claude moved into Google Workspace.


- [Mistral releases Large 4, a 1T-parameter open-weight multimodal model](https://x.com/MistralAI/status/2107457414387622310) (Mistral AI, release, Models): 1T total, 49B active, natively multimodal, and Mistral says it leads open models from the US or Europe on aggregate benchmarks. Europe's biggest open release yet.
- [OpenAI releases new mathematical results from an internal frontier model](https://x.com/OpenAI/status/2107596713791767021) (OpenAI, news, Research): Results were reviewed with an independent advisory group of mathematicians, a step toward credible AI contributions to research maths rather than benchmark claims.
- [Claude now works inside Google Docs, Sheets and Slides](https://x.com/claudeai/status/2107522596845822135) (Claude, news, Agents): A sidebar that reads and edits the open file puts Claude directly into Google's own suite, competing with Gemini on its home turf.
- [OpenAI opens the Decisions API to all developers](https://x.com/OpenAIDevs/status/2107573382229188645) (OpenAI Developers, release, Agents): Lets apps pick a model, tool or action in near real time from one call, moving routing logic out of agent code and into the platform.
- [Google DeepMind releases EmbeddingGemma 2 for on-device multimodal embeddings](https://x.com/GoogleDeepMind/status/2107502286758895878) (Google DeepMind, release, Open source): One small open model embeds text, code, images, audio and video in a shared space, useful for local retrieval in agents without a server.
- [Building Git infrastructure for agent-scale development](https://github.blog/engineering/architecture-optimization/building-git-infrastructure-for-agent-scale-development/) (GitHub Engineering, blog, Infra): Agent-driven writes are straining shared Git storage. GitHub explains the architecture changes it is making to keep up.
- [What is Codemode](https://lucumr.pocoo.org/2026/10/6/codemode/) (Armin Ronacher, blog, Agents): Armin Ronacher on when having an agent write code beats tool calls, and why bash alone may not be enough. Sharp thinking on agent tool design.
