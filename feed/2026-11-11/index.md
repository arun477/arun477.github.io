# Gemini Decision 1 and Grok Bot 1.0; Runway opens Praxis-1

Google ships a decision model API, Grok Bot 1.0 brings shared team bots, and Runway open-sources a robot world action model. Plus DeepMind's AlphaGenome 2 and Perplexity's sandbox red-team results.


- [Alibaba opens Qwen4-Max in preview](https://x.com/Alibaba_Qwen/status/2120335993643684315) (Qwen, news, Models, 13:48 UTC): The first Qwen4 model is usable now in preview on Alibaba's Token platform, pitched at coding, front-end builds and agentic work. It is a preview, so treat it as an early look before the full Qwen4 family lands.
- [Cursor rebuilds Projects so teammates' agents work together](https://x.com/cursor_ai/status/2120295553309565139) (Cursor, news, Agents, 13:48 UTC): Projects is now multiplayer: every teammate and their agents share one workspace and can coordinate. It moves Cursor from one developer steering agents toward whole teams of agents working side by side.
- [n8n Labs releases Nod, an open-source personal agent](https://x.com/n8n_io/status/2120431328458076315) (n8n, news, Agents, 13:48 UTC): Nod runs on your own computer with its own browser and works across apps and sites for chores like call prep, collecting invoices or cancelling subscriptions, with the AI provider you pick. It is an open alternative to hosted personal agents.
- [Google launches the Gemini Decisions API with Gemini Decision 1](https://x.com/Google/status/2120583966272983331) (Google, release, Models): A model that scores up to 1,000 yes/no, choice or rating questions per input in one pass, in about 200 ms at $0.10 per 1M tokens. Google now joins OpenAI in selling decision models for agent workflows.
- [Grok Bot 1.0 brings shared bots that work with whole teams](https://x.com/bot/status/2120582957782200586) (x.com, news, Agents): Bots can now be shared across a team, work inside Slack and Teams, and join meetings. It moves personal agents into team workflows; the launch post passed 16M views.
- [Runway releases Praxis-1, an open-weight world action model for robots](https://x.com/runwayml/status/2120533081182577116) (Runway, release, Open source): Apache 2.0 weights for a model that turns video pretraining into robot control, ranked first on NVIDIA's RoboLab-120. A strong open base for teams building robot agents.
- [DeepMind's AlphaGenome 2 predicts how DNA variants act in specific cell types](https://x.com/GoogleDeepMind/status/2120532824465805749) (x.com, news, Research): It models how each cell type reads the same genome, so researchers can trace a genetic variant to the cells where a disease actually unfolds.
- [Perplexity red-teams its agent sandbox with 12 models](https://www.perplexity.ai/hub/blog/escaping-space-part-ii) (Perplexity, paper, Security): Models tried to escape the VM and bypass network policy. Findings: standard capture-the-flag setups can steer agents away from the boundary being tested, and security-tuned models did not do better.
- [Why Cloudflare chose QuePaxa, an unusual consensus algorithm](https://blog.cloudflare.com/choosing-quepaxa/) (Cloudflare, blog, Infra): Cloudflare's new Meerkat control plane uses QuePaxa, a leaderless consensus algorithm, because Raft and Paxos stall when a leader slows down on the open Internet. Explains the tradeoff and how it works.
- [Meta's Intelligent Delivery: making every unit of ads compute count](https://engineering.fb.com/2026/11/11/ml-applications/intelligent-delivery-serve-better-ads/) (Meta Engineering, blog, Infra): Meta's system predicts the marginal value of compute per ad request and shifts serving resources to match, adding about 10% ranking performance. Now uses agents to detect and respond to system shifts.
