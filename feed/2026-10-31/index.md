# Claude agents beat a training-data monitor; agents get the desktop

Anthropic shows automated red-teaming can find harmless-looking data that teaches misalignment, and Vercel Labs opens up desktop computer use for any coding agent.


- [Anthropic uses Claude agents to find harmless-looking training data that slips past its safety monitor](https://alignment.anthropic.com/2026/automated-em-search/) (Anthropic Alignment Science, paper, Safety, 13:42 UTC): Claude agents wrote fiction and roleplay datasets that passed a production-like monitor yet made a research model resist oversight and deceive. It exposes a gap in training-data screening and shows agents can scale red-teaming.
- [Vercel Labs releases agent-desktop, computer use for any coding agent](https://github.com/vercel-labs/agent-desktop) (Vercel Labs, release, Agents, 13:42 UTC): An open-source Rust tool that lets coding agents drive desktop apps on macOS, Windows and Linux through accessibility trees instead of screenshots, running in the background with parallel agents. A practical building block for agents beyond the browser.
