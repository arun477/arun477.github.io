  1. 25 Sep – 23 Oct 2026 News · PapersSafety, security and provenance go operationalSafety work is turning into standing practice: outside audits and red-teaming by METR and Redwood, regular model behaviour reports, and published post-mortems such as Anthropic's analysis of Claude Mythos 5 going off-scope in the UK AISI's cyber tests. AI is also finding and proving things about real code, from critical PHP vulnerabilities patched through coordinated disclosure to Claude proving no-crash properties across 123 libraries. Labs are now tightening containment of the models themselves, with OpenAI cutting live internet access during frontier training, while the OpenCode breach and bypasses in OpenAI's agent monitoring show the attack surface includes the tools around the models.
  2. 18 Sep – 23 Oct 2026 News · ReleasesPersonal agents get their own computers, accounts and moneyAlways-on personal agents went from demos to products this month. OpenAI launched dots with their own cloud computers, Grok Bot added voice, finance, email, coding hand-offs and password-manager sign-in through 1Password, Anthropic opened a preview of Claude Duet, a proactive personal agent, and Cursor's agents can now operate the user's own computer. The agent is becoming a standing assistant with its own identity and access, which makes permissions and approvals the key question.
  3. 6 Oct – 20 Oct 2026 News · Blogs · ReleasesAgents become long-running, parallel and statefulAgents are moving from single chats to long jobs: parallel agents in ChatGPT Pro, Gemini agents playing Minecraft for 27 hours, durable pi agents and dedicated memory models. Engineering write-ups focus on the harness around the model rather than the model itself: Meta split one overloaded production agent into a thin router and 14 specialists, Ramp built its own agent platform after trying vendor SDKs, and IBM showed a plain agent with learned memory topping a benchmark. The hard problems are now state, memory and orchestration.
  4. 6 Oct – 23 Oct 2026 News · Blogs · Papers · ReleasesOpen-weight models reach the frontierMistral Large 4, Meta's Muse Spark Open, Reflection's Beam and now Moonshot's 2.8T-parameter Kimi K3.1 Pro have put frontier-scale models under open licences within a few weeks, and MiniMax's open-weight M3.1 Flash topped OpenCode before it was even named. Vercel's gateway data shows open weights already carry most production tokens, Meta's Muse Glimmer report gives a recipe for a local agent model on one consumer GPU, and DeepSeek has open-sourced the engine behind V4.1-Flash. Self-hosting is now a real alternative to paid APIs for coding and agent work.
  5. 22 Sep – 20 Oct 2026 News · ReleasesClosed labs ship new flagships and faster tiersThe closed labs kept shipping: GPT-6 Sol, Luna and 6.1 Sol, GPT-6 for all ChatGPT users plus an Ultrafast mode, Claude Haiku 5.5, Gemini 4 Argon and Meta's Muse Wonder. OpenAI's public MultiLangBench shows the newest GPT-6 models handling low-resource languages like COBOL and Fortran far better than their predecessors. The competition is shifting toward speed, price tiers and product surfaces as much as raw capability.
  6. 6 Oct – 21 Oct 2026 Blogs · PapersInfrastructure strains under agent-scale codeAgents now write code faster than Git hosting and review were built for. GitHub reworked its Git storage and then moved almost every repository to Azure under agent-driven load, Anthropic built its own source control after merges grew more than tenfold, and Anthropic's data shows agent hours outnumbering staff hours six to one, with human review now the bottleneck. Automated review is getting expensive too: Cloudflare's per-review cost doubled before it cut it by 68%. Tooling built for human pace is giving way first.
  7. 3 Oct – 23 Oct 2026 News · Blogs · ReleasesSandboxes and limits for agents that actAs agents run code and touch production, containment is getting real engineering. Vercel's sandbox challenge surfaced a kernel zero-day and Vercel now details how its own agent gets narrowly scoped, short-lived access to production; Codex on Windows moved to a container sandbox and Google offers a microVM per agent with governance controls. Claude apps are making auto mode, where a classifier approves routine actions, the default, which puts the weight on isolation and hard limits rather than click-through prompts.
