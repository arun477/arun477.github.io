Open-weight models reach the frontier

Mistral Large 4, Meta's Muse Spark Open, Reflection's Beam and now Moonshot's 2.8T-parameter Kimi K3.1 Pro have put frontier-scale models under open licences within a few weeks, and MiniMax's open-weight M3.1 Flash topped OpenCode before it was even named. Vercel's gateway data shows open weights already carry most production tokens, Meta's Muse Glimmer report gives a recipe for a local agent model on one consumer GPU, and DeepSeek has open-sourced the engine behind V4.1-Flash. Self-hosting is now a real alternative to paid APIs for coding and agent work.
