Agents become long-running, parallel and stateful

Agents are moving from single chats to long jobs: parallel agents in ChatGPT Pro, Gemini agents playing Minecraft for 27 hours, durable pi agents and dedicated memory models, and now GitHub rebuilding Copilot around parallel agent sessions that span repos and route each task across models. Engineering write-ups focus on the harness around the model: Meta split one overloaded agent into a router and 14 specialists, Ramp and LangChain built their own agent platforms, Cursor's Agent SDK packages agents as versioned code with evals, and Mistral offers a stateful Responses API. The hard problems are now state, memory, orchestration and testing.
