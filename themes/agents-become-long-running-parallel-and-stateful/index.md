# Agents become long-running, parallel and stateful

Agents are moving from single chats to long jobs: parallel agents in ChatGPT Pro, Gemini agents playing Minecraft for 27 hours, durable pi agents and dedicated memory models, and GitHub rebuilding Copilot around parallel agent sessions. The harness keeps expanding: Cursor Cloud Agents now scaffold, host and share live web apps from a prompt, Mistral Studio runs long-lived managed agents with approvals, sandboxes and tracing, and Figma post-trained its own design-editing model so its agent can edit the canvas reliably. Anthropic's write-up of agent memory treats offline "dreaming" as the pass that corrects bad notes, builds lasting memory and preloads the next session. The hard problems remain state, memory, orchestration and specialized tools around the model.

## Evidence

- [Anthropic on agent memory: dreaming to correct, organize and preload notes](https://www.anthropic.com/research/components-of-agent-memory) (Anthropic Engineering, blog, 2026-11-06): Engineering write-up of how Claude keeps experience across sessions, and how offline "dreaming" fixes bad notes, builds wiki-style memory and decides what to load into the next session.
- [Cursor Cloud Agents can build, host and share live web apps from a prompt](https://cursor.com/docs/cloud-agent/apps) (cursor.com, news, 2026-11-05): Describe a tool and Cursor scaffolds it, provisions Postgres if needed, runs security checks, and returns a shareable hosted URL behind Cursor auth or a public link.
- [Mistral Studio adds managed agents and apps for durable enterprise agent deployments](https://mistral.ai/news/build-with-studio/) (mistral.ai, news, 2026-11-05): Studio now runs long-lived managed agents with approvals, sandboxes and tracing, plus one-command app deploy, on shared infrastructure with Le Chonk.
- [GitHub Universe 2026: Copilot app, Copilot Fusion model routing and multi-repo Copilot projects](https://github.blog/news-insights/company-news/github-universe-2026-evolving-every-layer-of-the-stack/) (GitHub Blog, news, 2026-10-29): GitHub is rebuilding Copilot around agents: one app from issue to merge, parallel agent sessions across repos, and Fusion, which routes each task across models and scored near Opus 5.5 Max at half the cost.
- [How Figma post-trained its own design-editing model for the Figma agent](https://www.figma.com/blog/training-a-figma-fluent-editing-model/) (Figma, blog, 2026-10-29): Frontier models didn't understand Figma's syntax, so Figma fine-tuned its own model for small canvas edits. Against expert designers it matches or beats the old agent 62% of the time, and users undo its work 60% less often.
- [Mistral launches a Responses API in public preview for building agents](https://x.com/MistralAI/status/2115443720371814478) (Mistral AI, release, 2026-10-28): Each response returns the model's answer, its reasoning and its tool calls as separate items, giving agent builders on Mistral a structured loop similar to OpenAI's Responses API.
- [How LangChain built Content Studio, its in-house design agent](https://www.langchain.com/blog/design-agent) (LangChain, blog, 2026-10-27): Build log of an agent that makes videos, graphics and decks from a Slack prompt: a sandbox per thread as a designer's computer, design principles as context, rules deleted as models improve, and long async runs with approvals. Harness is open source.
- [Cursor's Agent SDK is generally available: agents as code, with evals](https://cursor.com/changelog/agent-sdk) (Cursor, release, 2026-10-26): Agents become a versioned folder of Markdown instructions, TypeScript tools, skills and MCP connections, triggered from GitHub, Slack, webhooks or cron, tested with built-in evals and deployed to Cursor or self-hosted. It is the harness behind Bugbot and Security Review.
- [Building Laminar, Ramp's in-house managed agents platform](https://builders.ramp.com/post/building-laminar) (Ramp Engineering, blog, 2026-10-20): After trying provider agent SDKs, managed agent APIs and open-source frameworks, Ramp built its own harness, which now runs its accounting, SMS assistant and coding agents. A candid case for owning the agent loop.
- [IBM's ALTK-Evolve tops τ²-bench with learned memory instead of a frontier model](https://huggingface.co/blog/ibm-research/altk-evolve-bc) (Hugging Face, blog, 2026-10-20): A basic GPT-4.1 ReAct agent learns guidelines from past runs and beats the retail entries on τ²-bench without weight updates. It measures the cost: more tokens, not more turns.
- [The thin orchestrator: how Meta made its production agents reliable](https://engineering.fb.com/2026/10/19/ml-applications/thin-orchestrator-ai-agent-architecture/) (Meta Engineering, blog, 2026-10-19): One all-knowing agent hallucinated once it held too much context, so Meta split it into a 1,300-line router that does no domain work and 14 specialist agents. A concrete pattern for multi-agent systems in production.
- [ChatGPT Pro can now run multiple agents on one task in parallel](https://x.com/OpenAI/status/2111192259073094035) (OpenAI, news, 2026-10-17): GPT-6 Pro splits a task across agents you can monitor and review individually, a sign that parallel multi-agent workflows are moving from dev tools into the mainstream chat product.
- [Tencent open-sources Hy Memory 2.0, a model just for agent memory](https://x.com/TencentHunyuan/status/2111027329816465435) (Tencent Hy, news, 2026-10-17): A 30B (3B active) model, framework and cross-tool sync for deciding what agents should remember. Memory is becoming its own layer of the agent stack rather than a prompt trick.
- [Pi Durable on Cloudflare](https://earendil.com/posts/pi-durable-on-cloudflare/) (Earendil, blog, 2026-10-17): A worked build of long-running pi agents: one session per Durable Object with SQLite storage, hibernation when idle, alarm wakeups and a search subagent.
- [Four Gemini 4 Argon agents beat Minecraft from scratch in 27 hours](https://x.com/GoogleDeepMind/status/2111127991401247033) (Google DeepMind, news, 2026-10-16): Working only through code and text, the agents wrote 2,783 programs and split up jobs over chat, a vivid long-horizon multi-agent result.
- [Improving Deep Agents with harness engineering](https://www.langchain.com/blog/improving-deep-agents-with-harness-engineering) (LangChain, blog, 2026-10-13): Starting from 52.8% with GPT-5.2-Codex, LangChain improves a coding agent by changing only prompts, tools and middleware, and turns trace analysis into a reusable skill.
- [Qwen releases QwenGyre for elastic RL on very long agent tasks](https://x.com/Alibaba_Qwen/status/2109633085658808515) (Qwen, release, 2026-10-12): An elastic scheduler reallocates GPUs during training, targeting the cost problem of RL on agents that run for very long horizons.
- [What is Codemode](https://lucumr.pocoo.org/2026/10/6/codemode/) (Armin Ronacher, blog, 2026-10-06): Armin Ronacher on when having an agent write code beats tool calls, and why bash alone may not be enough. Sharp thinking on agent tool design.
- [OpenAI opens the Decisions API to all developers](https://x.com/OpenAIDevs/status/2107573382229188645) (OpenAI Developers, release, 2026-10-06): Lets apps pick a model, tool or action in near real time from one call, moving routing logic out of agent code and into the platform.
